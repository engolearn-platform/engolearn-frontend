# EngoLearn Design Principles

## Brand

EngoLearn is a professional English learning application
for Vietnamese learners.

The visual direction is Modern Minimalism.

Avoid:
- childish gamification
- excessive gradients
- excessive shadows
- decorative UI without functional purpose

Prioritize:
- clarity
- readability
- whitespace
- professional appearance
- learning focus

## Typography

Use Hanken Grotesk.

Body text should normally use 16px.

Vietnamese diacritics must have sufficient line height.

When English and Vietnamese are displayed together,
English should have stronger visual hierarchy.

## Layout

Use a mobile-first fluid layout.

Default horizontal page margin:
20px.

Use the spacing scale defined in tokens.yaml.
