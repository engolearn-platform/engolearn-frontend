# Quản lý ngữ pháp

Mở `/admin/grammar` với tài khoản Admin hoặc Content Manager của app. Grammar dùng cùng hệ thống đăng nhập và layout quản trị với Placement.

Admin đăng nhập từ trang chung được đưa vào Bộ đề Placement. Content Manager vào Grammar. Nếu mở một trang được bảo vệ trước đăng nhập, hệ thống quay lại đúng trang đó. Menu tài khoản học viên có liên kết Quản trị nội dung. Trên màn hình nhỏ, thanh đầu trang quản trị có lựa chọn Chuyển mục quản trị để vào các module theo quyền.

- [Mười màn quản trị](00-grammar-topic-list.md)
- [Luồng học viên và hướng dẫn chạy](../00-grammar-learning.md)

Kiểm tra tích hợp ngày 20/11/2026 trên bản ổ D: cùng phiên ADMIN đăng nhập từ trang chủ vào Placement, đọc được Bộ đề, 320 câu ngân hàng và danh sách kết quả; chuyển sang Grammar bằng menu ở chiều rộng 900px. Chủ đề nháp “Thì hiện tại đơn” và một bài học nháp được lưu qua API thật rồi tải lại, chưa xuất bản. Thanh quản trị ở màn hình hẹp chia hai hàng để giữ nút tài khoản đọc được.
